# SpecKit Play — dossier de cadrage

Application locale Windows, ouverte dans un navigateur, servant d'interface visuelle à **Claude Code + GitHub Spec Kit**.

## Lire dans cet ordre
1. `00-RESUME-ECHANGES.md` — décisions et attentes issues de la discussion.
2. `01-BRIEF-SPECKIT.md` — texte prêt à fournir à `/speckit.specify`.
3. `02-SPEC-FONCTIONNELLE.md` — exigences, flux, critères d'acceptation.
4. `03-SPEC-TECHNIQUE.md` — architecture envisagée, risques, points à valider.
5. `04-PARCOURS-ET-VUES.md` — inventaire des écrans.
6. `wireframes/` — détail des huit vues.
7. `prototype-wireframes.html` — maquettes navigables, sans backend.

## Statut
Document de **pré-spécification à confirmer avec Spec Kit**. Aucune intégration Claude Code opérationnelle n'est livrée ici. Les maquettes sont démonstratives.
